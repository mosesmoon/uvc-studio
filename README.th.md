# แนะนำฟีเจอร์ของ UVC Studio

[English](README.md) · [台灣正體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md) · **ไทย** · [Tiếng Việt](README.vi.md)

UVC Studio 1.1.0 เป็นแอปเนทีฟสำหรับการ์ดแคปเจอร์ที่ทำงานแบบออฟไลน์ทั้งหมด รองรับ Linux, Windows และ Meta Quest ใช้เล่นเกมคอนโซลผ่านการ์ดแคปเจอร์ UVC รุ่นใดก็ได้ด้วยความหน่วงต่ำ อัปสเกลเป็น 4K เพิ่มเอฟเฟกต์เรโทรหรือความลึก 3D ซ้อนภาพเว็บแคมลงบนเกม บันทึกวิดีโอ และจับภาพหน้าจอได้ โดยไม่เชื่อมต่อเครือข่ายเลย 1.1.0 ซึ่งเป็นเวอร์ชันทางการแรก เปิดตัว UVC Studio แพลทินัมบน Meta Quest: การอัปสเกล 4K และความลึก 3D ยังใช้ฟรีได้อย่างละ 30 นาทีต่อวัน และซื้อครั้งเดียวเพื่อปลดล็อกถาวร ส่วนเวอร์ชัน Linux และ Windows ยังฟรีและเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT แล้ว

## เริ่มต้นใช้งาน

1. เสียบการ์ดแคปเจอร์เข้ากับพอร์ต USB แล้วเปิด UVC Studio **หน้าจอเริ่มต้น** จะตรวจ 3 รายการแบบเรียลไทม์ ได้แก่ "การ์ดแคปเจอร์" "เสียงเกม" และ "เว็บแคม (ไม่บังคับ)" ถ้าไม่พบการ์ดจะขึ้นว่า "ไม่พบ — เสียบเข้ากับพอร์ต USB" ถ้าไม่พบเสียงจะขึ้นว่า "ไม่พบ (เฉพาะภาพ)"
2. กด **เชื่อมต่อ** บนหน้าจอเริ่มต้นหรือที่มุมขวาบน หรือกดปุ่ม `Enter` หากเปิด **เชื่อมต่ออัตโนมัติ** ไว้ (การตั้งค่า → ทั่วไป เปิดอยู่เป็นค่าเริ่มต้น) UVC Studio จะเชื่อมต่อเองทันทีที่เสียบการ์ด และเชื่อมต่อทันทีตอนเปิดแอปหากเสียบการ์ดไว้แล้ว
3. เริ่มเล่นได้เลย กดปุ่มเดิม (**ตัดการเชื่อมต่อ**) หรือ `Ctrl+D` เพื่อปิดทุกอย่าง ถ้ากำลังบันทึกอยู่ แอปจะหยุดบันทึกและเซฟไฟล์ให้ก่อน

ไม่มีการหยุดชั่วคราวหรือเล่นต่ออีกแล้ว UVC Studio มีแค่สองสถานะคือเชื่อมต่ออยู่หรือไม่ได้เชื่อมต่อ ถ้าถอดการ์ดออก จะมีข้อความแจ้งข้อผิดพลาดใต้สถานะการเชื่อมต่อและกลับไปที่หน้าจอเริ่มต้น หากเปิดการเชื่อมต่ออัตโนมัติไว้ แอปจะเชื่อมต่อใหม่เองเมื่อเสียบการ์ดกลับเข้าไป

## การจับภาพและเสียง

การ์ดแคปเจอร์ UVC ทุกรุ่นใช้งานได้โดยไม่ต้องลงไดรเวอร์เพิ่ม ไม่ว่าจะเป็น ShadowCast, Elgato, AVerMedia, Magewell หรือดองเกิล HDMI USB 3 ทั่วไป ก็ใช้งานเหมือนกันหมด

- **ใช้โหมดที่การ์ดรองรับจริง**: ความละเอียดและอัตราเฟรมมาจากรายการที่การ์ดรายงาน เรียงจากมากไปน้อยพร้อมป้าย 4K, QHD, Full HD, HD หรือ SD ค่าเริ่มต้นคือความละเอียดสูงสุดที่ทำได้ตั้งแต่ 59 fps ขึ้นไป รูปแบบเลือกได้ระหว่างอัตโนมัติ ไม่บีบอัด (หน่วงน้อยที่สุด) หรือบีบอัด (ได้ความละเอียดและอัตราเฟรมสูงกว่า)
- **เลือกอุปกรณ์ให้ถูกตัว**: หากยังไม่เคยบันทึกการเลือกไว้ แอปจะดูจากชื่ออุปกรณ์เพื่อเลือกการ์ดแคปเจอร์ เสียงของการ์ด และเว็บแคม จึงไม่เข้าใจผิดว่ากล้องในตัวหรือกล้องเสมือนเป็นการ์ดแคปเจอร์ อุปกรณ์ที่ชื่อซ้ำกันจะมี (2), (3)… ต่อท้าย
- **ความหน่วงต่ำ**: แสดงเฟรมล่าสุดเสมอ ไม่มีเฟรมเก่าค้างคิว
- **จำการตั้งค่าไว้ให้** และตรวจพบการ์ดที่เสียบหรือถอดระหว่างใช้งานได้ทันที
- **ฟังเสียง** (`L`): ฟังเสียงเกมผ่านลำโพงหรือหูฟัง เมื่อเลื่อนเมาส์ไปที่ปุ่มใน Dock จะมีสวิตช์เปิด/ปิด ระดับเสียง และเอาต์พุตที่ใช้อยู่ คลิกบรรทัด "เอาต์พุต" เพื่อไปที่ การตั้งค่า → เสียง ได้ทันที
- **แสดงโหมดที่ใช้งานจริง**: การตั้งค่า → แหล่งสัญญาณ แสดงสตรีมจริง เช่น 3840 × 2160 · 60 fps · YUY2
- **เสียงบน Meta Quest**: แอปอ่านเสียงของการ์ดผ่าน USB โดยตรง (USB Audio Class 1 และ 2 รวมถึงดองเกิล MacroSilicon MS2109) ที่ การตั้งค่า → เสียง → อินพุตเสียง → "เสียงจากการ์ดแคปเจอร์ (USB)" การตั้งค่า → เสียง → "ช่องเสียงเกม" เลือก **สเตอริโอ 2CH** (ค่าเริ่มต้น) หรือ **เซอร์ราวด์ 6CH** ได้ โดยจะเล่นเป็น 5.1 เมื่อการ์ดมีโหมด 6 ช่อง (เช่น CJ-16) และคอนโซลส่ง 5.1 ทาง HDMI (เช่น Switch 2 ที่ตั้งเป็นเซอร์ราวด์) ส่วนการบันทึกยังเป็นสเตอริโอ
- **กู้คืนอัตโนมัติบน Quest**: ถ้าการ์ดหยุดส่งภาพ แอปจะเปิดการ์ดใหม่เอง (สูงสุด 2 ครั้ง) หากยังไม่มีภาพ จะแนะนำให้ตรวจแหล่งสัญญาณ HDMI หรือถอดการ์ดแล้วเสียบใหม่

## การประมวลผลภาพ

การอัปสเกล 4K ทั้ง 4 แบบ เอฟเฟกต์เรโทร 3 แบบ และความลึก 3D ประมวลผลบน GPU ทีละเฟรม จึงไม่เพิ่มความหน่วงนอกจากเวลาที่ GPU ใช้คำนวณ

**อัปสเกล 4K** (`U`): คลิกปุ่มใน Dock หรือกด `U` เพื่อเปิด/ปิด เลื่อนเมาส์ไปที่ปุ่มเพื่อเลือกแบบ และกด `Shift+U` เพื่อสลับไปแบบถัดไป ส่วน การตั้งค่า → ภาพ → อัปสเกล 4K มีตัวเลือก "ปิด" "FSR" "Anime4K" "Lanczos" และ "NIS" เมื่อเลือกแบบใดแบบหนึ่ง การอัปสเกลจะเปิดทันที และถ้าเลือก "ปิด" แอปจะจำแบบที่ใช้ล่าสุดไว้ให้ในครั้งหน้า

| แบบ | หลักการ | เหมาะกับ | อัตราขยาย |
| --- | --- | --- | --- |
| อัปสเกล 4K แบบ FSR (ค่าเริ่มต้น) | AMD FidelityFX Super Resolution 1: ขยายแบบปรับตามขอบภาพ (EASU) แล้วเพิ่มความคมด้วย RCAS | เกมและวิดีโอทุกประเภท | 720p / 1080p เป็น 4K, แหล่งสัญญาณ SD สูงสุด 3 เท่า |
| อัปสเกล 4K แบบ Anime4K สำหรับแอนิเมชัน | โครงข่ายประสาทเทียม Anime4K ×2 (เดสก์ท็อปใช้ขนาด M, Quest ใช้ S) ส่วนที่เหลือใช้ FSR | อนิเมะ การ์ตูน ภาพลายเส้น | โครงข่ายขยาย 2 เท่า แล้วขยายต่อจนถึง 4K |
| อัปสเกล 4K แบบ Lanczos + CAS | รีแซมเปิล Lanczos-3 (6 แทปต่อแกน) แล้วเพิ่มความคมด้วย AMD FidelityFX CAS | การขยายแบบคลาสสิกที่เป็นกลาง | จนถึง 4K |
| อัปสเกล 4K แบบ NIS | NVIDIA Image Scaling 1.0.3: ขยายแบบ 6 แทปตามทิศทางขอบภาพพร้อมเพิ่มความคมแบบปรับตัว | รายละเอียดคมชัด | สูงสุด 2 เท่า ส่วนที่เกินใช้ Lanczos-3 |

ตัวอัปสเกลจะคำนวณใหม่เฉพาะเมื่อมีเฟรมใหม่เข้ามา ถ้า Quest ไม่รองรับเรนเดอร์ทาร์เก็ตแบบ half-float ตัว Anime4K จะสลับไปใช้ FSR แทน

- **เอฟเฟกต์เรโทร** (`C`): เลื่อนเมาส์ไปที่ปุ่มใน Dock เพื่อเลือก "ปิด" "CRT" "VHS" หรือ "อาร์เคด" กด `C` เพื่อสลับไปตามลำดับนี้ ส่วนการคลิกปุ่มจะสลับระหว่าง "ปิด" กับเอฟเฟกต์ที่ใช้ล่าสุด และเลือกแบบเดียวกันได้ที่ การตั้งค่า → ภาพ → เอฟเฟกต์เรโทร เอฟเฟกต์จะทำงานบนภาพสุดท้ายหลังการอัปสเกล 4K จึงใช้ร่วมกับอัปสเกลได้ และจะปรากฏในภาพที่จับ วิดีโอที่บันทึก และบนจอยักษ์ของ Quest ด้วย แอปจะจำตัวเลือกไว้ให้
  - **CRT**: ทีวีจอแก้ว มีสล็อตมาสก์แบบสลับแถว เส้นสแกนที่เข้มขึ้นตามความสว่าง จอโค้งนูนเล็กน้อย และขอบมืดแบบนุ่มนวล
  - **VHS**: วิดีโอเทปตามบ้าน ภาพนุ่มลงเล็กน้อย สีเลอะไปทางขวา โทนสีอุ่นที่ซีดลงเล็กน้อยและสีดำที่ไม่ดำสนิท สัญญาณรบกวนจาง ๆ ภาพสั่นเบา ๆ และบางครั้งมีแถบแทร็กกิ้งจาง ๆ เลื่อนลงมาตามจอ (ยังอ่านตัวหนังสือได้ชัด)
  - **อาร์เคด**: จอตู้เกมอาร์เคด ภาพความละเอียดต่ำพร้อมเส้นสแกนสีเข้มหนา ตะแกรง RGB แนวตั้ง แสงเรืองรอบส่วนที่สว่าง สีสด และจอโค้งเล็กน้อย
- **ความลึก 3D** (`D`): ประเมินว่าส่วนไหนของภาพอยู่ใกล้หรือไกล เลื่อนเมาส์ไปที่ปุ่ม หรือเปิด การตั้งค่า → ความลึก 3D เพื่อเลือก **รูปแบบความลึก** และปรับ **ความแรงของเอฟเฟกต์** แบบ "เอฟเฟกต์ความลึก (เสริมภาพ 2D เท่านั้น)" จะทำให้ฉากหน้าคมและสดขึ้น ส่วนฉากหลังนุ่มและฟุ้งขึ้น รูปแบบสเตอริโอสำหรับจอ 3D อธิบายไว้ในหัวข้อถัดไป ส่วนในโหมดอิมเมอร์ซีฟของ Quest เมื่อเลือก "จอยักษ์ 3D สเตอริโอ" จอยักษ์จะกลายเป็นภาพ 3D สเตอริโอจริง กด `D` หรือคลิกปุ่มเพื่อสลับระหว่าง "ไม่มีความลึก" กับรูปแบบที่ใช้ล่าสุด
- **ความสว่าง คอนทราสต์ ความอิ่มตัวของสี** (การตั้งค่า → ภาพ): ปรับได้ตั้งแต่ −40 ถึง +40 โดย 0 คือภาพต้นฉบับ ส่วน **แกมมา** ปรับได้ตั้งแต่ 0.70 ถึง 1.40 (1.00 คือภาพต้นฉบับ) ค่าที่มากกว่า 1.00 ทำให้โทนกลางสว่างขึ้น ค่าที่น้อยกว่าทำให้โทนกลางเข้มขึ้น โดยสีดำและสีขาวไม่เปลี่ยน มี **สไตล์ภาพ** สำเร็จรูปให้เลือกคือ "ธรรมชาติ" "สมจริง" (คอนทราสต์เป็นธรรมชาติแบบเส้นโค้งรูปตัว S อ่อน ๆ สีสันไม่จัดจนเกินไป และยังเก็บรายละเอียดในส่วนมืดไว้) "สดใส" "ฟิล์ม" และ "ห้องสว่าง" (เพิ่มแกมมาขึ้นเล็กน้อย ให้มองเห็นฉากมืดได้ชัดแม้อยู่ในห้องสว่าง)
- **พลิกซ้ายขวา** (`X`): กลับด้านภาพทั้งหมดจากซ้ายเป็นขวา

## รูปแบบ 3D สเตอริโอ (Linux / Windows)

บนเดสก์ท็อป เมนูรูปแบบความลึก (ที่ปุ่มความลึก 3D หรือ การตั้งค่า → ความลึก 3D) ยังมีรูปแบบสเตอริโออีก 4 แบบที่ส่งภาพ 3D สเตอริโอจริงไปยังจอ 3D ตั้งจอให้เป็นรูปแบบ 3D เดียวกันแล้วสลับเป็นเต็มจอ (`F`) ภาพที่จับและวิดีโอที่บันทึกยังคงเป็น 2D แอปจะตรวจหาตัวอักษรและ HUD แล้วคงไว้ใกล้ระนาบของจอ พร้อมทำให้ความลึกเปลี่ยนอย่างนุ่มนวลขึ้น ตัวอักษรจึงขยับไปทั้งตัวในภาพของตาทั้งสองข้าง ไม่ดูเหมือนถูกตัดแยกอีกต่อไป

| รูปแบบ | ใช้กับ |
| --- | --- |
| ซ้าย-ขวา เต็ม (3840×1080) | แว่น XR ในโหมด 3D เช่น XREAL, VITURE และ RayNeo |
| ซ้าย-ขวา ครึ่ง | ทีวี 3D |
| บน-ล่าง | ทีวี 3D และโปรเจกเตอร์ |
| แว่นแดง / ฟ้า | แว่น 3D แบบแอนะกลิฟแดง/ฟ้า |

## ภาพซ้อนเว็บแคม การจับภาพ และการบันทึก

เห็นอย่างไรก็บันทึกอย่างนั้น ทั้งเอฟเฟกต์ การพลิกภาพ และภาพซ้อนเว็บแคม จะอยู่ในภาพที่จับและวิดีโอที่บันทึกทุกไฟล์

- **ภาพซ้อนเว็บแคม** (`W`): วางภาพเว็บแคมไว้บนเกมที่มุมใดมุมหนึ่งในสี่มุม (ค่าเริ่มต้นคือล่างซ้าย) เลือกขนาดได้ S, M หรือ L (18%, 26% หรือ 36% ของความกว้างภาพ)
  - ลากไปวางตรงไหนก็ได้ พอปล่อยเมาส์ ภาพจะเลื่อนเข้ามุมที่ใกล้ที่สุดเอง หมุนล้อเมาส์บนภาพซ้อนเพื่อเปลี่ยนขนาด
  - เมื่อเลื่อนเมาส์ไปบนภาพซ้อน จะมีแถบเครื่องมือเล็ก ๆ ที่มี "พลิกซ้ายขวา" "ขนาด" และ "นำออก"
  - ที่ปุ่มใน Dock (หรือ การตั้งค่า → ภาพซ้อนเว็บแคม) ตั้งค่า "กล้อง" "คุณภาพ" (720p · 30 fps, 1080p · 30 fps หรือ 1080p · 60 fps) "ขนาด" "มุม" "พลิกซ้ายขวา" และ **สลับภาพ** ได้ เมื่อสลับภาพ เว็บแคมจะเป็นภาพหลัก และการ์ดแคปเจอร์จะเป็นภาพซ้อน
- **จับภาพ** (`S`): บันทึกภาพปัจจุบันเป็นไฟล์ PNG
- **บันทึก** (`R`): ไฟล์ MP4 วิดีโอ H.264 และเสียง AAC 192 kbit/s บิตเรตปรับตามสตรีม (กว้าง × สูง × fps × 0.12 อยู่ในช่วง 8–50 Mbit/s: 1080p60 ประมาณ 15 Mbit/s และ 4K60 ที่ 50 Mbit/s) ระหว่างบันทึก สถานะการเชื่อมต่อจะแสดง REC และเวลาที่บันทึกไปแล้ว
  - **Windows:** ไม่มีตัวเข้ารหัสแบบซอฟต์แวร์มาให้ การบันทึกต้องใช้ตัวเข้ารหัสกราฟิกของ NVIDIA (NVENC), AMD (AMF) หรือ Intel หรือตัวเข้ารหัส H.264 ที่มากับ Windows (Media Foundation โดย Windows รุ่น "N" ต้องติดตั้ง Media Feature Pack ก่อน)
  - **Linux:** ไม่มีตัวเข้ารหัสแบบซอฟต์แวร์มาให้เช่นกัน การบันทึกต้องใช้กราฟิก Intel หรือ AMD ผ่าน VA-API (ต้องติดตั้งไดรเวอร์ VA-API), NVIDIA NVENC (ไดรเวอร์แบบ proprietary) หรือ AMD AMF
  - ถ้าไม่มีเลยสักตัว ฟีเจอร์อื่นยังใช้ได้ตามปกติ แต่เมื่อกดบันทึกจะขึ้นข้อความ "ไม่มีตัวเข้ารหัสวิดีโอ: การบันทึกต้องใช้กราฟิก NVIDIA, AMD หรือ Intel"
- **บันทึกไมโครโฟน** (`M`): ผสมเสียงพูดของคุณเข้ากับเสียงเกม
- **ชื่อไฟล์และตำแหน่งที่บันทึก**: `UVC Studio 2026-10-06 21.30.15.png` / `.mp4` (วันที่และเวลา ถ้าชื่อซ้ำจะเติมตัวเลขต่อท้าย) ภาพที่จับเก็บไว้ที่ **รูปภาพ/UVC Studio** และวิดีโอเก็บไว้ที่ **วิดีโอ/UVC Studio** พร้อมการแจ้งเตือน "บันทึกไว้ที่ Pictures/UVC Studio แล้ว" และปุ่ม **ดู** นอกจากนี้ การตั้งค่า → ทั่วไป ยังมี "เปิดโฟลเดอร์ภาพที่จับ" และ "เปิดโฟลเดอร์วิดีโอที่บันทึก" บน Quest ไฟล์จะเก็บในแกลเลอรี (`Pictures/UVC Studio` และ `Movies/UVC Studio`) ดูได้จากแอปไฟล์หรือผ่าน USB

## Meta Quest

เสียบการ์ดแคปเจอร์เข้ากับพอร์ต USB-C ของเฮดเซ็ต แล้วเล่นเกมบนหน้าต่างที่ปรับขนาดได้หรือบนจอเสมือนขนาดยักษ์ พร้อมภาพ 3D สเตอริโอจริง

- **ติดตั้ง**: จาก Meta Horizon Store (เร็ว ๆ นี้) หรือเปิดโหมดนักพัฒนาบนแว่นแล้วติดตั้ง `UVCStudio-Quest-v1.1.0-Free.apk` จาก Releases ของโปรเจกต์นี้ (Meta Quest Developer Hub, SideQuest หรือ `adb install`) ซื้อแพลทินัมได้เฉพาะในเวอร์ชันที่ติดตั้งจากสโตร์
- **เชื่อมต่อ**: ใช้อะแดปเตอร์ USB-C OTG หรือฮับก็ได้ เมื่อระบบถามว่าจะเปิด UVC Studio ตอนเสียบการ์ดหรือไม่ ให้กดอนุญาต (เลือก "ทุกครั้ง") และอนุญาตสิทธิ์กล้องกับไมโครโฟนที่ Android กำหนดสำหรับการ์ดแคปเจอร์ USB แอปไม่ใช้กล้องของตัวเฮดเซ็ตเลย
- **การถอดรหัส**: การ์ดที่ส่งภาพแบบ H.264 และ HEVC จะถอดรหัสด้วยตัวถอดรหัสฮาร์ดแวร์ในเฮดเซ็ต ส่วน FFmpeg ที่มาพร้อมแอปใช้กับ MJPEG เท่านั้น
- **หน้าต่าง 2D** (ค่าเริ่มต้น): อินเทอร์เฟซเต็มรูปแบบเหมือนเวอร์ชันเดสก์ท็อป อยู่ในแผง Horizon OS ที่ย้ายและปรับขนาดได้ จีบนิ้วสองครั้งบนภาพเพื่อเข้าหรือออกจากโหมดเต็มจอ
- **โหมดอิมเมอร์ซีฟ**: ปุ่มเฮดเซ็ตท้ายสุดของ Dock (ถัดจากการตั้งค่า) ใช้สลับไปยังจอเสมือนขนาดยักษ์และกลับมา ทุกครั้งที่สลับ UVC Studio จะตัดการเชื่อมต่อแล้วเชื่อมต่อใหม่ให้เอง
- **ความลึก 3D บน Quest**: ในหน้าต่าง 2D เลือกได้ระหว่าง "ไม่มีความลึก" กับ "เอฟเฟกต์ความลึก" ส่วนในโหมดอิมเมอร์ซีฟเลือกได้ระหว่าง "ไม่มีความลึก" กับ "จอยักษ์ 3D สเตอริโอ"

| ในโหมดอิมเมอร์ซีฟ | วิธีทำ |
| --- | --- |
| คลิกแผงควบคุม | ชี้ด้วยคอนโทรลเลอร์แล้วกดไกปืน หรือจีบนิ้วด้วยมือ |
| ย้ายแผงควบคุม | จับแถบสีขาวใต้แผงแล้วลาก ดันออกหรือดึงเข้าเพื่อปรับระยะ การตั้งค่า → VR → "รีเซ็ตตำแหน่งแผง" เพื่อคืนตำแหน่งเดิม |
| ย้ายจอ | จับแถบสีขาวใต้จอแล้วลาก ดันมือออกหรือดึงเข้าเพื่อปรับระยะ |
| ปรับขนาดจอ | ชี้ที่มุมจอจนมีกรอบมุมปรากฏ แล้วจีบนิ้วค้างไว้และลาก |
| ใกล้ขึ้น / ไกลขึ้น, เล็กลง / ใหญ่ขึ้น | ก้านอนาล็อกขึ้น / ลง, ซ้าย / ขวา |
| ซ่อนหรือแสดงแผงควบคุม | จีบนิ้วสองครั้งบนจอ หรือกด B, Y หรือปุ่มเมนู |
| จัดให้อยู่ตรงกลาง | กดปุ่ม Meta ค้างไว้ |
| ค่าที่ตั้งไว้ของจอ | การตั้งค่า → VR: พื้นหลัง (พาสทรูหรือห้องมืด), รูปทรงจอ (แบนหรือโค้ง), ขนาดจอ, ระยะห่างของจอ, อัตรารีเฟรช 72 / 90 / 120 Hz (ค่าเริ่มต้น 90) |

- **เมนูระบบ**: ขณะเปิดอยู่ แอปยังวาดภาพต่อ แต่ซ่อนตัวชี้และปิดเสียง
- **ลดความร้อน**: อัปสเกลเท่าที่จอยักษ์แสดงผลได้จริงเท่านั้น (ประมาณ 30 พิกเซลต่อองศา กว้างสุด 2560) และเรนเดอร์ภาพสำหรับตาซ้ายขวาที่ขนาดเดียวกัน
- **ป้องกันความร้อนเกิน**: ตรวจทั้งสถานะความร้อนของ Android และการแจ้งเตือนความร้อนของ OpenXR เมื่อเฮดเซ็ตเริ่มร้อนจะเปลี่ยนไปใช้ FSR และ 72 Hz เมื่อร้อนเกินไปจะหยุดอัปสเกลและความลึก 3D ชั่วคราว การตั้งค่าของคุณจะไม่ถูกเปลี่ยน และจะมีการแจ้งเตือนเมื่อเฮดเซ็ตเย็นลงแล้ว
- **แสดงภาระงาน**: ขณะเชื่อมต่อ การตั้งค่า → เกี่ยวกับ แสดงเวลา GPU ต่อเฟรม ความละเอียดที่ใช้ประมวลผล และอุณหภูมิเฮดเซ็ต

## อินเทอร์เฟซ

อินเทอร์เฟซทั้งหมดใช้สไตล์ Liquid Glass เป็นพื้นผิวโปร่งแสงแบบกระจกฝ้า ซึ่งขณะเชื่อมต่ออยู่จะเห็นภาพเกมด้านหลังแบบเบลอและสีสดขึ้น

- **แถบด้านบน**: ด้านซ้ายเป็นโลโก้ UVC Studio ตรงกลางเป็น**สถานะการเชื่อมต่อ** ("ไม่ได้เชื่อมต่อ" / จุดสีเขียวกับอุปกรณ์ · ความละเอียด · fps ถ้าอัปสเกลอยู่จะเพิ่ม ▸ 4K และชื่อตัวอัปสเกล ถ้าเปิดความลึก 3D จะเพิ่ม · 3D / ขณะบันทึกเป็น REC สีแดงกะพริบพร้อมเวลาบันทึก) ด้านขวาเป็นเมนูภาษาและปุ่ม **เชื่อมต่อ / ตัดการเชื่อมต่อ** ข้อผิดพลาดจะแสดงเป็นตัวอักษรสีแดงใต้สถานะสักครู่
- **Dock**: แบ่งเป็น 4 กลุ่ม คือ "จับภาพ บันทึก บันทึกไมโครโฟน" · "อัปสเกล 4K เอฟเฟกต์เรโทร ความลึก 3D พลิกซ้ายขวา" · "ภาพซ้อนเว็บแคม ฟังเสียง" · "การตั้งค่า" ปุ่มที่เมาส์ชี้อยู่จะขยายใหญ่ขึ้น ฟีเจอร์ที่เปิดอยู่จะเรืองแสงด้วยสีไล่ระดับของแบรนด์ และทูลทิปทุกอันจะแสดงปุ่มลัดด้วย เวอร์ชันอยู่มุมซ้ายล่าง ปุ่มเต็มจออยู่มุมขวาล่าง
- **การตั้งค่า**: แผงกระจกขนาดใหญ่ที่จัดการ์ดเป็นไม่เกิน 3 คอลัมน์อย่างสมดุล ปรับได้ทุกอย่างโดยไม่ต้องเลื่อน เรียงตามลำดับ แหล่งสัญญาณ เสียง ภาพ ภาพซ้อนเว็บแคม การแสดงผล VR (โหมดอิมเมอร์ซีฟของ Quest) ทั่วไป ความลึก 3D และเกี่ยวกับ ในการจัดวางอัตโนมัติ การ์ด "ความลึก 3D" จะอยู่ติดเหนือการ์ด "เกี่ยวกับ" การ์ด "เกี่ยวกับ" แสดงเวอร์ชัน ขณะเชื่อมต่อจะแสดงเวลา GPU ต่อเฟรมและความละเอียดที่ใช้ประมวลผลด้วย (บน Quest มีอุณหภูมิเฮดเซ็ตเพิ่ม) พร้อมปุ่ม "สัญญาอนุญาตโอเพนซอร์ส" ส่วนข้อความเรื่องความเป็นส่วนตัวอยู่ในหน้าที่เปิดจากปุ่มนี้
  - **ยุบการ์ด**: ปุ่มกลมรูปลูกศรที่ขวาสุดของหัวการ์ด ทางขวาของไอคอนแม่กุญแจ จะยุบการ์ดให้เหลือแค่หัว (ชื่อ แม่กุญแจ และปุ่มยุบยังอยู่) และกดอีกครั้งเพื่อขยาย การ์ดด้านล่างจะเลื่อนขึ้นมา ไม่มีการ์ดใดย้ายคอลัมน์ และแอปจะจำการ์ดที่ยุบไว้
  - **จัดวางการ์ดเอง**: การ์ดทุกใบมีไอคอนแม่กุญแจที่มุมขวาบนของส่วนหัว และทุกการ์ดจะถูกล็อกไว้ตั้งแต่แรก คลิกแม่กุญแจ ("ปลดล็อกเพื่อย้าย") แล้วลากการ์ดที่ส่วนหัวไปยังตำแหน่งอื่นในสามคอลัมน์ จะมีช่องว่างแสดงตำแหน่งที่การ์ดจะลงไป กด `Esc` เพื่อยกเลิกการลาก คลิกแม่กุญแจอีกครั้ง ("ล็อกตำแหน่ง") เพื่อตรึงการ์ดไว้ การ์ดที่ล็อกอยู่จะอยู่กับที่ ส่วนการ์ดที่ปลดล็อกจะย้ายไปมาระหว่างการ์ดเหล่านั้น แอปจะจำการจัดวางและการ์ดที่ปลดล็อกไว้สำหรับการเปิดครั้งถัดไป ปุ่ม "รีเซ็ตการจัดวาง" ที่อยู่ข้างปุ่มปิด ซึ่งจะแสดงเฉพาะเมื่อใช้การจัดวางของคุณเอง จะคืนค่าการจัดวางอัตโนมัติและล็อกการ์ดทั้งหมด หากหน้าต่างแคบเกินกว่าจะแสดงสามคอลัมน์ แอปจะแสดงการจัดวางอัตโนมัติ และเก็บการจัดวางของคุณไว้จนกว่าหน้าต่างจะกว้างพออีกครั้ง ในหน้าต่าง 2D ของ Quest ใช้ตัวชี้ของคอนโทรลเลอร์ทำได้แบบเดียวกัน
- **ภาษา**: 台灣正體中文, English, Deutsch, Français, Italiano, Español, Português, 日本語, 한국어, 简体中文, ไทย และ Tiếng Việt เลือกได้จากเมนูกระจกที่มุมขวาบน เมื่อเปิดครั้งแรก แอปจะใช้ภาษาตามระบบ

## แป้นพิมพ์ลัด (Linux / Windows)

กด `?` หรือ `H` ในแอปเพื่อดูรายการเดียวกันนี้ กดปุ่มใดก็ได้หรือคลิกเพื่อปิด

| ปุ่ม | การทำงาน |
| --- | --- |
| `Enter` | เชื่อมต่อ |
| `Ctrl+D` | ตัดการเชื่อมต่อ |
| `S` | จับภาพ |
| `R` | เริ่มหรือหยุดบันทึก |
| `M` | เปิด / ปิดบันทึกไมโครโฟน |
| `L` | เปิด / ปิดฟังเสียง |
| `W` | เปิด / ปิดภาพซ้อนเว็บแคม |
| `X` | พลิกซ้ายขวา |
| `U` | เปิด / ปิดอัปสเกล 4K |
| `Shift+U` | ตัวอัปสเกลถัดไป (และเปิดอัปสเกล) |
| `C` | เอฟเฟกต์เรโทร: ปิด → CRT → VHS → อาร์เคด |
| `D` | ความลึก 3D: สลับระหว่าง "ไม่มีความลึก" กับรูปแบบที่ใช้ล่าสุด |
| `O` หรือ `Ctrl+,` | การตั้งค่า |
| `F` หรือ `F11` | เต็มจอ |
| `Esc` | ยกเลิกการลากการ์ด ออกจากเต็มจอ หรือปิดการตั้งค่า |
| `?` หรือ `H` | แป้นพิมพ์ลัด |
| `Ctrl` `+` / `−` / `0` | ขยาย / ย่อ / คืนค่าขนาดอินเทอร์เฟซ |
