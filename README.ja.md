# UVC Studio 機能紹介

[English](README.md) · [台灣正體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · **日本語** · [한국어](README.ko.md) · [简体中文](README.zh-CN.md) · [ไทย](README.th.md) · [Tiếng Việt](README.vi.md)

UVC Studio 1.1.0 は、Linux・Windows・Meta Quest で動く、完全オフラインのネイティブなキャプチャーカード用アプリです。どんな UVC キャプチャーカードでもゲーム機を低遅延で遊べて、4K アップスケール、レトロ表示や 3D 奥行き、Web カメラのオーバーレイ、録画、スナップショットまでこなし、ネットワークには一切接続しません。最初の正式版となる 1.1.0 では、Meta Quest 向けに UVC Studio プラチナを導入しました。4K アップスケールと 3D 奥行きはそれぞれ 1 日 30 分まで無料で、一度の購入でずっと無制限になります。Linux 版と Windows 版は引き続き無料で、MIT ライセンスのオープンソースになりました。

## はじめかた

1. キャプチャーカードを USB に接続して UVC Studio を起動します。**起動画面**では「キャプチャーカード」「ゲーム音声」「Web カメラ（任意）」の 3 項目をリアルタイムで確認します。カードがなければ「見つかりません — USB に接続してください」、音声がなければ「見つかりません（映像のみ）」と表示されます。
2. 起動画面または右上の **接続** をクリックするか、`Enter` キーを押します。**自動で接続**（設定 → 一般、初期設定はオン）が有効なら、カードを挿した瞬間に自動で接続し、起動時にすでに挿さっている場合もそのまま接続します。
3. あとは遊ぶだけです。同じボタン（**切断**）または `Ctrl+D` ですべてを閉じます。録画中なら、先に録画を終えてファイルを保存します。

一時停止や再開はありません。UVC Studio の状態は「接続中」か「未接続」の 2 つだけです。カードが抜けると接続状態の下にエラーが表示されて起動画面に戻り、自動接続がオンなら、カードを挿し直したときに自動で再接続します。

## キャプチャーとサウンド

ShadowCast、Elgato、AVerMedia、Magewell から手頃な USB 3 HDMI ドングルまで、UVC キャプチャーカードなら追加ドライバーなしで同じように使えます。

- **キャプチャーカード本来のモード**：解像度とフレームレートはカードが報告する一覧をそのまま使い、大きい順に 4K・QHD・Full HD・HD・SD のラベル付きで並びます。初期状態では 59 fps 以上を出せる最大の解像度を選びます。フォーマットは自動・非圧縮（最小遅延）・圧縮（より高い解像度とフレームレート）から選べます。
- **正しいデバイスを自動選択**：まだ何も保存されていない場合は、デバイス名からキャプチャーカード、その音声、Web カメラを判別します。内蔵カメラや仮想カメラをキャプチャーカードと取り違えることはありません。同じ名前のデバイスには (2)、(3)… が付きます。
- **低遅延**：常に最新のフレームだけを表示し、古い映像がたまることはありません。
- **設定を記憶**し、アプリの起動中にカードを抜き差ししても検出します。
- **モニター**（`L`）：ゲーム音をスピーカーやヘッドホンで聴けます。Dock のボタンにマウスを合わせると、オン／オフのスイッチ、音量、現在の出力先が表示され、「出力」の行から 設定 → サウンド に移動できます。
- **現在のモードを表示**：設定 → ソース に実際のストリーム（例：3840 × 2160 · 60 fps · YUY2）が表示されます。
- **Quest の音声**：アプリがキャプチャーカードの音を USB から直接読み取ります（USB Audio Class 1・2、MacroSilicon MS2109 ドングルにも対応）。設定 → サウンド → オーディオ入力 →「キャプチャーカードの音声（USB）」です。設定 → サウンド →「ゲーム音声のチャンネル」で **ステレオ 2CH**（既定）か **サラウンド 6CH** を選べます。6 チャンネルモードを持つカード（CJ-16 など）と、HDMI で 5.1ch を出力するゲーム機（サラウンドに設定した Switch 2 など）なら 5.1ch で再生されます。録画はステレオのままです。
- **Quest の自動復帰**：カードから映像が届かなくなるとアプリが自動で開き直し（最大 2 回）、それでも映らなければ HDMI ソースの確認かカードの挿し直しを案内します。

## 映像処理

4 種類の 4K アップスケール、3 種類のレトロ表示、3D 奥行きはすべて GPU でフレームごとに処理され、GPU の処理時間以外に遅延は増えません。

**4K アップスケール**（`U`）：Dock のボタンをクリックするか `U` でオン／オフを切り替えます。ボタンにマウスを合わせると方式を選べ、`Shift+U` で次の方式に切り替わります。設定 → 映像 → 4K アップスケール では「オフ」「FSR」「Anime4K」「Lanczos」「NIS」から選べます。方式を選ぶとアップスケールがオンになり、「オフ」にしても前回の方式は記憶されます。

| 方式 | しくみ | 向いている映像 | 倍率 |
| --- | --- | --- | --- |
| FSR 4K アップスケール（標準） | AMD FidelityFX Super Resolution 1：エッジ適応型の EASU で拡大し、RCAS でシャープ化 | ゲームやあらゆる映像 | 720p / 1080p から 4K、SD ソースは最大 3 倍 |
| アニメ専用 Anime4K 4K アップスケール | Anime4K ×2 ニューラルネットワーク（デスクトップは M、Quest は S）、残りは FSR で拡大 | アニメ、カートゥーン、線画 | ネットワークで 2 倍、その後 4K まで |
| Lanczos + CAS 4K アップスケール | Lanczos-3 リサンプリング（各軸 6 タップ）+ AMD FidelityFX CAS シャープ化 | クラシックで素直な拡大 | 4K まで |
| NIS 4K アップスケール | NVIDIA Image Scaling 1.0.3：エッジ方向に沿った 6 タップ拡大と適応シャープ化 | くっきりしたディテール | 最大 2 倍、それ以上は Lanczos-3 |

アップスケールは新しいフレームが届いたときだけ計算し直します。Quest が半精度浮動小数点のレンダーターゲットに対応していない場合、Anime4K は FSR に切り替わります。

- **レトロ表示**（`C`）：Dock のボタンにマウスを合わせて「オフ」「CRT」「VHS」「アーケード」から選びます。`C` を押すとこの順に切り替わり、ボタンをクリックすると「オフ」と前回使った効果が切り替わります。設定 → 映像 → レトロ表示 でも同じように選べます。効果は 4K アップスケールの後にかかるのでアップスケールと同時に使え、スナップショットや録画、Quest の巨大スクリーンにも反映されます。選んだ効果は次回も引き継がれます。
  - **CRT**：ブラウン管テレビ。互い違いのスロットマスク、明るさに応じて濃さが変わる走査線、ゆるやかに湾曲した画面とやわらかな周辺減光を再現します。
  - **VHS**：家庭用ビデオテープ。やや柔らかな画質、右ににじむ色、少し色あせた暖色寄りの色調と浮いた黒、かすかなノイズと揺れ、ときどき上から下へ流れる薄いトラッキングノイズ（文字は問題なく読めます）を再現します。
  - **アーケード**：アーケード筐体のモニター。低解像度のラスター、太く黒い走査線、縦縞の RGB アパーチャーグリル、明るい部分のほのかな発光、鮮やかな色、わずかな湾曲を再現します。
- **3D 奥行き**（`D`）：映像の中の近いもの・遠いものを推定します。ボタンにマウスを合わせるか、設定 → 3D 奥行き を開くと、**奥行きの形式**と**効果の強さ**を設定できます。「奥行き効果（2D 強調のみ）」では手前がよりくっきり鮮やかに、背景はやわらかくかすんだ印象になります。デスクトップ版のステレオ 3D 形式は次の節で説明します。Quest のイマーシブモードで「ステレオ 3D の大画面」を選ぶと、巨大スクリーンが本物の立体 3D になります。`D` またはボタンのクリックで「奥行きなし」と前回の形式が切り替わります。
- **明るさ・コントラスト・彩度**（設定 → 映像）：−40〜+40 で、0 が元の映像です。**ガンマ**は 0.70〜1.40（1.00 が元の映像）で、1.00 より大きいと中間調が明るく、小さいと中間調が深くなり、黒と白はそのままです。**ルック**のプリセットとして「ナチュラル」「リアル」（ゆるやかな S 字カーブの自然なコントラストと控えめな色で、暗部のディテールも残ります）「ビビッド」「フィルム」「明るい部屋」（ガンマを少し上げ、明るい部屋でも暗いシーンが見やすくなりました）があります。
- **ミラー**（`X`）：映像全体を左右反転します。

## ステレオ 3D 形式（Linux / Windows）

デスクトップ版では、奥行きの形式メニュー（3D 奥行きのボタン、または 設定 → 3D 奥行き）に 4 つのステレオ形式があり、本物の立体 3D を 3D ディスプレイに送れます。ディスプレイ側も同じ 3D 形式にして全画面（`F`）にしてください。スナップショットと録画は 2D のままです。文字や HUD は自動で検出されて画面の面の近くに保たれ、奥行きの変化もなめらかになったので、文字は左右の目で一体のまま動き、裂けて見えることはありません。

| 形式 | 対象 |
| --- | --- |
| サイドバイサイド・フル（3840×1080） | 3D モードの XR グラス（XREAL、VITURE、RayNeo など） |
| サイドバイサイド・ハーフ | 3D テレビ |
| トップ・アンド・ボトム | 3D テレビ、プロジェクター |
| 赤青メガネ | 赤青アナグリフメガネ |

## Web カメラのオーバーレイ、スナップショット、録画

見えているとおりに保存されます。エフェクト、ミラー、Web カメラのオーバーレイも、すべてのスナップショットと録画にそのまま入ります。

- **Web カメラのオーバーレイ**（`W`）：Web カメラの映像をゲーム画面の四隅のどこか（初期設定は左下）に、S・M・L（映像の幅の 18%・26%・36%）のサイズで重ねます。
  - ドラッグして好きな場所に動かせます。ドロップすると一番近い隅へすっと移動します。オーバーレイの上でマウスホイールを回すとサイズが変わります。
  - マウスを合わせると「ミラー」「サイズ」「削除」の小さなツールバーが出ます。
  - Dock のボタン（または 設定 → Web カメラのオーバーレイ）では「カメラ」「画質」（720p · 30 fps、1080p · 30 fps、1080p · 60 fps）「サイズ」「表示位置」「ミラー」と **映像を入れ替え** を設定できます。入れ替えると Web カメラがメインの映像に、キャプチャーカードがオーバーレイになります。
- **スナップショット**（`S`）：現在の映像を PNG で保存します。
- **録画**（`R`）：H.264 映像と 192 kbit/s の AAC 音声による MP4 です。ビットレートはストリームに合わせて決まります（幅 × 高さ × fps × 0.12、8〜50 Mbit/s の範囲。1080p60 で約 15 Mbit/s、4K60 で 50 Mbit/s）。録画中は接続状態に REC と経過時間が表示されます。
  - **Windows**：ソフトウェアエンコーダーは同梱していません。録画には NVIDIA（NVENC）、AMD（AMF）、Intel の GPU エンコーダーか、Windows に組み込まれた H.264 エンコーダー（Media Foundation。Windows の「N」エディションには Media Feature Pack が必要）が必要です。
  - **Linux**：こちらもソフトウェアエンコーダーは同梱していません。録画には VA-API 経由の Intel / AMD GPU（VA-API ドライバーが必要）、NVIDIA NVENC（プロプライエタリドライバー）、AMD AMF のいずれかが必要です。
  - どれもない場合でもほかの機能はすべて使えますが、録画しようとすると「ビデオエンコーダーがありません。録画には NVIDIA、AMD、Intel のいずれかの GPU が必要です」と表示されます。
- **マイクを録音**（`M`）：自分の声をゲーム音とミックスします。
- **ファイル名と保存先**：`UVC Studio 2026-10-06 21.30.15.png`／`.mp4`（日付と時刻。同じ名前があれば番号を追加）。スナップショットは **ピクチャ／UVC Studio**、録画は **ビデオ／UVC Studio** に保存され、「Pictures/UVC Studio に保存しました」という通知と **表示** ボタンが出ます。設定 → 一般 の「スナップショットのフォルダーを開く」「録画のフォルダーを開く」からも開けます。Quest ではギャラリー（`Pictures/UVC Studio` と `Movies/UVC Studio`）に保存され、ファイルアプリや USB 経由で確認できます。

## Meta Quest

ヘッドセットの USB-C ポートにキャプチャーカードを挿せば、サイズを変えられるウィンドウでも巨大な仮想スクリーンでも遊べて、本物の立体 3D も楽しめます。

- **インストール**：Meta Horizon Store から（近日公開）。または、ヘッドセットを開発者モードにして、このプロジェクトの Releases から `UVCStudio-Quest-v1.1.0-Free.apk` をインストールします（Meta Quest Developer Hub、SideQuest、`adb install`）。プラチナはストアからインストールした版でのみ購入できます。
- **接続**：USB-C OTG アダプターやハブ経由でも使えます。カードを接続したときに UVC Studio を開くかどうかの確認が出たら許可し（「常に」にチェック）、Android が USB キャプチャーカードに求めるカメラとマイクの権限も許可してください。ヘッドセット本体のカメラは一切使いません。
- **デコード**：H.264 / HEVC のカードはヘッドセット内蔵のハードウェアデコーダーでデコードします。同梱の FFmpeg は MJPEG 専用です。
- **2D ウィンドウ**（標準）：デスクトップ版と同じインターフェイスを、移動やサイズ変更ができる Horizon OS のパネルで表示します。映像をダブルピンチすると全画面のオン／オフを切り替えます。
- **イマーシブモード**：Dock の最後（設定の右）にあるヘッドセットのボタンで、巨大な仮想スクリーンとの間を切り替えます。切り替えのたびに UVC Studio が自動で切断・再接続します。
- **Quest の 3D 奥行き**：2D ウィンドウでは「奥行きなし」か「奥行き効果」、イマーシブモードでは「奥行きなし」か「ステレオ 3D の大画面」を選べます。

| イマーシブモードでの操作 | 方法 |
| --- | --- |
| コントロールパネルをクリック | コントローラーで指してトリガーを引く、または手でピンチ |
| コントロールパネルを移動 | パネル下の白いバーをつかんでドラッグ。押す・引くで距離が変わる。設定 → VR →「パネルの位置をリセット」で元に戻る |
| スクリーンを移動 | スクリーン下の白いバーをつかんでドラッグ。手を前に押す・手前に引くと距離が変わる |
| スクリーンのサイズを変更 | 角を指してブラケットが出たら、ピンチしてドラッグ |
| 近く／遠く、小さく／大きく | スティックの上／下、左／右 |
| コントロールパネルの表示／非表示 | スクリーン上でダブルピンチ、または B・Y・メニューボタン |
| 正面に戻す | Meta ボタンを長押し |
| スクリーンのプリセット | 設定 → VR：背景（パススルー／暗い部屋）、スクリーンの形（フラット／カーブ）、スクリーンの大きさ、スクリーンまでの距離、リフレッシュレート 72 / 90 / 120 Hz（標準は 90） |

- **システムメニュー**：開いている間もアプリは描画を続け、ポインターを隠して音声をミュートします。
- **発熱を抑える工夫**：アップスケールは巨大スクリーンで実際に見分けられる解像度（1 度あたり約 30 ピクセル、最大幅 2560）までにとどめ、左右の目の映像も同じサイズで描画します。
- **過熱保護**：Android の温度状態と OpenXR の温度通知を監視します。ヘッドセットが温まってくると FSR と 72 Hz に切り替え、熱くなりすぎるとアップスケールと 3D 奥行きを一時停止します。設定そのものは変わらず、冷えたら通知でお知らせします。
- **負荷の表示**：接続中は 設定 → 情報 に 1 フレームの GPU 時間、処理解像度、ヘッドセット温度が表示されます。

## インターフェイス

インターフェイス全体が Liquid Glass スタイルです。半透明のすりガラスのような面で、接続中は背後のゲーム映像をぼかして彩度を高めたものが透けて見えます。

- **上部バー**：左に UVC Studio のロゴ、中央に**接続状態**（「未接続」／緑の点とデバイス · 解像度 · fps、アップスケール中は ▸ 4K と方式名、3D 奥行きがオンなら · 3D／録画中は点滅する赤い REC と録画時間）、右に言語メニューと **接続／切断** ボタン。エラーは接続状態の下に赤い文字で数秒間表示されます。
- **Dock**：「スナップショット・録画・マイクを録音」「4K アップスケール・レトロ表示・3D 奥行き・ミラー」「Web カメラのオーバーレイ・モニター」「設定」の 4 グループです。ポインターを合わせたボタンが拡大し、オンの機能はブランドのグラデーションで光り、ツールチップにはショートカットキーも表示されます。左下にバージョン、右下に全画面ボタンがあります。
- **設定**：大きなガラスパネルにカードを最大 3 列でバランスよく並べ、スクロールせずにすべて調整できます。ソース、サウンド、映像、Web カメラのオーバーレイ、表示、VR（Quest のイマーシブモード）、一般、3D 奥行き、情報の順で、自動レイアウトでは「3D 奥行き」カードは「情報」のすぐ上にあります。「情報」には、バージョン、接続中の 1 フレームの GPU 時間と処理解像度（Quest ではヘッドセット温度も）、「オープンソースライセンス」ボタンが表示されます。プライバシーについての説明は、このボタンで開く画面にあります。
  - **カードを折りたたむ**：各カードの見出しの右端、鍵アイコンの右にある丸い矢印ボタンで、カードを見出しだけ（タイトル・鍵・折りたたみボタンは残ります）に折りたたみ、もう一度押すと開きます。下のカードは上に詰まり、列が変わることはなく、折りたたんだ状態は記憶されます。
  - **カードを自分で並べ替える**：各カードの見出しの右上に鍵アイコンがあり、最初はすべてのカードがロックされています。鍵アイコンをクリック（「移動するにはロックを解除」）してから、カードの見出しをドラッグすると、3 列の中の別の場所へ移動できます。置かれる位置には空きスペースが表示され、`Esc` でドラッグを取り消せます。もう一度鍵アイコンをクリック（「位置をロック」）すると固定されます。ロックされたカードはその場にとどまり、ロックを解除したカードがその間を移動します。配置とロックを解除したカードは記憶され、次回の起動時にもそのままです。自分の配置を使っているときだけ、閉じるボタンの隣に「レイアウトをリセット」が表示され、クリックすると自動レイアウトに戻り、すべてのカードがロックされます。ウィンドウが狭くて 3 列に収まらないときは自動レイアウトで表示され、自分の配置は保存されたまま、ウィンドウを広げると元に戻ります。Quest の 2D ウィンドウでも、コントローラーのポインターで同じように操作できます。
- **言語**：台灣正體中文、English、Deutsch、Français、Italiano、Español、Português、日本語、한국어、简体中文、ไทย、Tiếng Việt の 12 言語を、右上のガラスメニューから選べます。初回起動時はシステムの言語に合わせます。
- **テーマ**：自動（06:00〜18:00 はライト）、ダーク、ライト。
- **インターフェイスの大きさ**：画面に合わせて自動調整します（1080p で 100%、1440p で約 135%、4K で 200%）。設定 → 表示 または `Ctrl` `+` / `−` / `0` で変更できます。
- **フォントとアイコン**：Manrope と IBM Plex Sans（タイ語は IBM Plex Sans Thai、中国語・日本語・韓国語は Noto Sans CJK TC）。アイコンはすべて UVC Studio オリジナルです。
- **全画面**：`F`、`F11`、右下のボタン、または映像をダブルクリック。`Esc` で戻ります。

## プライバシー

UVC Studio はすべてお使いのデバイス上で動作します。映像、音声、録画がデバイスの外に出ることはありません。アカウント不要、アップロードなし、トラッキングなしで、アプリがネットワークに接続することもありません。Meta Quest 版でのプラチナの購入と購入状況の確認は、ヘッドセットの Meta Horizon Store サービスを通じて行われ、UVC Studio 自体は何も送信しません。
