# UVC Studio 기능 소개

[English](README.md) · [台灣正體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [日本語](README.ja.md) · **한국어** · [简体中文](README.zh-CN.md) · [ไทย](README.th.md) · [Tiếng Việt](README.vi.md)

UVC Studio 1.1.0는 Linux, Windows, Meta Quest에서 동작하는 네이티브 캡처 카드 앱으로, 네트워크 연결 없이 완전히 오프라인으로 작동합니다. 어떤 UVC 캡처 카드로든 콘솔 게임을 낮은 지연으로 즐기고, 4K 업스케일과 레트로 화면, 3D 입체감을 더하고, 게임 화면 위에 웹캠을 띄우고, 녹화와 스냅샷까지 할 수 있습니다. 첫 정식 버전인 1.1.0은 Meta Quest에 UVC Studio 플래티넘을 도입했습니다. 4K 업스케일과 3D 입체감은 각각 하루 30분 무료로 쓸 수 있고, 한 번 구매하면 영구히 무제한이 됩니다. Linux와 Windows 버전은 계속 무료이며 이제 MIT 라이선스의 오픈 소스입니다.

## 시작하기

1. 캡처 카드를 USB에 꽂고 UVC Studio를 실행합니다. **시작 화면**에서 '캡처 카드', '게임 오디오', '웹캠 (선택)' 세 가지를 실시간으로 확인합니다. 캡처 카드가 없으면 '찾을 수 없음 — USB에 연결하세요', 소리가 없으면 '찾을 수 없음 (영상만)'이 표시됩니다.
2. 시작 화면이나 오른쪽 위의 **연결** 버튼을 누르거나 `Enter` 키를 누릅니다. **자동 연결**(설정 → 일반, 기본값 켜짐)이 켜져 있으면 캡처 카드를 꽂자마자 알아서 연결되고, 앱을 실행할 때 이미 꽂혀 있어도 바로 연결됩니다.
3. 이제 플레이하면 됩니다. 같은 버튼(**연결 해제**)이나 `Ctrl+D`로 모든 장치를 닫습니다. 녹화 중이었다면 먼저 녹화를 마치고 파일을 저장합니다.

일시 정지나 재개는 없습니다. UVC Studio는 연결되어 있거나, 연결되어 있지 않거나 둘 중 하나입니다. 캡처 카드가 빠지면 연결 상태 아래에 오류가 표시되고 시작 화면으로 돌아가며, 자동 연결이 켜져 있으면 카드를 다시 꽂을 때 자동으로 다시 연결됩니다.

## 캡처와 사운드

ShadowCast, Elgato, AVerMedia, Magewell은 물론 저렴한 USB 3 HDMI 동글까지, UVC 캡처 카드라면 별도 드라이버 없이 똑같이 사용할 수 있습니다.

- **캡처 카드의 실제 모드**: 해상도와 프레임 레이트는 캡처 카드가 알려 주는 목록을 그대로 따르며, 큰 것부터 4K, QHD, Full HD, HD, SD 표시와 함께 나열됩니다. 기본으로는 59fps 이상을 낼 수 있는 가장 높은 해상도를 고릅니다. 포맷은 자동·비압축(최저 지연)·압축(더 높은 해상도와 프레임 레이트) 중에서 고를 수 있습니다.
- **알맞은 장치를 자동 선택**: 저장된 설정이 없으면 장치 이름을 보고 캡처 카드, 그 오디오, 웹캠을 골라냅니다. 노트북 내장 카메라나 가상 카메라를 캡처 카드로 착각하지 않습니다. 이름이 같은 장치에는 (2), (3)…이 붙습니다.
- **낮은 지연**: 항상 가장 최근 프레임만 보여 주므로 지난 화면이 쌓이지 않습니다.
- **설정을 기억**하고, 앱이 켜진 상태에서 캡처 카드를 꽂거나 뽑아도 바로 인식합니다.
- **듣기**(`L`): 게임 소리를 스피커나 헤드폰으로 들을 수 있습니다. Dock 버튼에 마우스를 올리면 켜기/끄기 스위치, 음량, 현재 출력 장치가 나타나고, '출력' 줄을 누르면 설정 → 사운드로 바로 이동합니다.
- **현재 모드 표시**: 설정 → 소스에 실제 스트림(예: 3840 × 2160 · 60 fps · YUY2)이 표시됩니다.
- **Quest 오디오**: 앱이 캡처 카드의 소리를 USB에서 직접 읽습니다(USB Audio Class 1·2, MacroSilicon MS2109 동글 포함). 설정 → 사운드 → 오디오 입력 → '캡처 카드 오디오 (USB)'입니다. 설정 → 사운드 → '게임 오디오 채널'에서 **스테레오 2CH**(기본값) 또는 **서라운드 6CH**를 고를 수 있습니다. 6채널 모드가 있는 카드(CJ-16 등)와 HDMI로 5.1을 출력하는 콘솔(서라운드로 설정한 Switch 2 등)이면 5.1로 재생되며, 녹화는 스테레오로 저장됩니다.
- **Quest 자동 복구**: 캡처 카드에서 화면이 들어오지 않으면 앱이 자동으로 다시 열고(최대 2회), 그래도 안 되면 HDMI 소스를 확인하거나 카드를 다시 꽂으라고 안내합니다.

## 화면 처리

네 가지 4K 업스케일, 세 가지 레트로 화면, 3D 입체감은 모두 GPU에서 프레임 단위로 처리되므로 GPU 연산 시간 외에는 지연이 늘지 않습니다.

**4K 업스케일**(`U`): Dock 버튼을 클릭하거나 `U`를 눌러 켜고 끕니다. 버튼에 마우스를 올리면 방식을 고를 수 있고, `Shift+U`로 다음 방식으로 바꿉니다. 설정 → 영상 → 4K 업스케일에서는 '끔', 'FSR', 'Anime4K', 'Lanczos', 'NIS' 중에서 고를 수 있습니다. 방식을 고르면 업스케일이 켜지고, '끔'을 골라도 마지막으로 쓴 방식은 기억됩니다.

| 방식 | 원리 | 잘 맞는 영상 | 배율 |
| --- | --- | --- | --- |
| FSR 4K 업스케일(기본) | AMD FidelityFX Super Resolution 1: 경계 적응형 EASU로 확대한 뒤 RCAS로 선명하게 | 게임과 모든 영상 | 720p / 1080p에서 4K로, SD 소스는 최대 3배 |
| 애니메이션 전용 Anime4K 4K 업스케일 | Anime4K ×2 신경망(데스크톱은 M, Quest는 S) 후 남은 배율은 FSR로 | 애니메이션, 카툰, 선화 | 신경망으로 2배, 이후 4K까지 |
| Lanczos + CAS 4K 업스케일 | Lanczos-3 리샘플링(축당 6탭) + AMD FidelityFX CAS 샤프닝 | 전통적이고 중립적인 확대 | 4K까지 |
| NIS 4K 업스케일 | NVIDIA Image Scaling 1.0.3: 경계 방향을 따르는 6탭 확대와 적응형 샤프닝 | 선명한 디테일 | 최대 2배, 그 이상은 Lanczos-3 |

업스케일은 새 프레임이 들어올 때만 다시 계산합니다. Quest가 반정밀도 부동소수점 렌더 타깃을 지원하지 않으면 Anime4K는 FSR로 바뀝니다.

- **레트로 화면**(`C`): Dock 버튼에 마우스를 올려 '끔', 'CRT', 'VHS', '아케이드' 중에서 고릅니다. `C`를 누르면 이 순서대로 바뀌고, 버튼을 클릭하면 '끔'과 마지막으로 쓴 효과 사이를 오갑니다. 설정 → 영상 → 레트로 화면에서도 똑같이 고를 수 있습니다. 효과는 4K 업스케일 다음에 적용되므로 업스케일과 함께 쓸 수 있고, 스냅샷과 녹화, Quest 대형 스크린에도 그대로 나타납니다. 고른 효과는 다음에 실행할 때도 유지됩니다.
  - **CRT**: 브라운관 TV. 엇갈린 슬롯 마스크, 밝기에 따라 짙어지는 주사선, 살짝 볼록한 화면과 부드러운 비네팅을 재현합니다.
  - **VHS**: 가정용 비디오테이프. 조금 부드러운 화질, 오른쪽으로 번지는 색, 살짝 바랜 따뜻한 색감과 들뜬 검은색, 옅은 노이즈와 잔잔한 흔들림, 가끔 위에서 아래로 흘러가는 옅은 트래킹 띠(글자를 읽는 데는 지장 없음)를 재현합니다.
  - **아케이드**: 아케이드 기기 모니터. 저해상도 래스터, 굵고 진한 주사선, 세로줄 RGB 애퍼처 그릴, 밝은 부분의 은은한 글로우, 선명한 색감, 살짝 휜 화면을 재현합니다.
- **3D 입체감**(`D`): 화면 속에서 가까운 것과 먼 것을 추정합니다. 버튼에 마우스를 올리거나 설정 → 3D 입체감을 열면 **입체감 형식**과 **효과 강도**를 정할 수 있습니다. '입체감 효과 (2D 강조만)'는 앞쪽을 더 선명하고 생생하게, 배경은 부드럽고 아련하게 만듭니다. 데스크톱용 스테레오 3D 형식은 다음 절에서 설명합니다. Quest 몰입 모드에서 '스테레오 3D 대형 화면'을 고르면 대형 스크린이 진짜 입체 3D가 됩니다. `D`를 누르거나 버튼을 클릭하면 '입체감 없음'과 마지막으로 쓴 형식 사이를 오갑니다.
- **밝기·대비·채도**(설정 → 영상): −40~+40이며 0이 원본입니다. **감마**는 0.70~1.40(1.00이 원본)으로, 1.00보다 높으면 중간 톤이 밝아지고 낮으면 중간 톤이 깊어지며, 검은색과 흰색은 그대로입니다. **스타일** 프리셋으로 '자연', '사실적'(완만한 S 커브의 자연스러운 대비와 절제된 색감, 어두운 부분의 디테일도 살아 있음), '비비드', '필름', '밝은 방'(감마를 조금 높여 밝은 방에서도 어두운 장면이 잘 보임)이 있습니다.
- **좌우 반전**(`X`): 화면 전체를 좌우로 뒤집습니다.

## 스테레오 3D 형식 (Linux / Windows)

데스크톱에서는 입체감 형식 메뉴(3D 입체감 버튼 또는 설정 → 3D 입체감)에 스테레오 형식 네 가지가 더 있어, 진짜 입체 3D를 3D 디스플레이로 보낼 수 있습니다. 디스플레이도 같은 3D 형식으로 맞추고 전체 화면(`F`)으로 전환하세요. 스냅샷과 녹화는 2D로 저장됩니다. 글자와 HUD는 자동으로 감지해 화면 평면 가까이에 두고 입체감도 더 매끄럽게 처리하므로, 글자가 양쪽 눈에서 한 덩어리로 움직여 갈라져 보이지 않습니다.

| 형식 | 대상 |
| --- | --- |
| 좌우 나란히, 풀 (3840×1080) | 3D 모드의 XR 글래스(XREAL, VITURE, RayNeo 등) |
| 좌우 나란히, 하프 | 3D TV |
| 위아래 | 3D TV, 프로젝터 |
| 적청 안경 | 적청 애너글리프 안경 |

## 웹캠 오버레이, 스냅샷, 녹화

보이는 그대로 저장됩니다. 효과, 좌우 반전, 웹캠 오버레이가 모든 스냅샷과 녹화에 그대로 들어갑니다.

- **웹캠 오버레이**(`W`): 웹캠 화면을 게임 화면의 네 모서리 중 한 곳(기본은 왼쪽 아래)에 S, M, L 크기(화면 너비의 18%, 26%, 36%)로 띄웁니다.
  - 원하는 곳으로 끌어다 놓으면 가장 가까운 모서리로 부드럽게 붙습니다. 오버레이 위에서 마우스 휠을 돌리면 크기가 바뀝니다.
  - 마우스를 올리면 '좌우 반전', '크기', '제거' 버튼이 있는 작은 도구 막대가 나타납니다.
  - Dock 버튼(또는 설정 → 웹캠 오버레이)에서 '카메라', '화질'(720p · 30 fps, 1080p · 30 fps, 1080p · 60 fps), '크기', '모서리', '좌우 반전'과 **화면 바꾸기**를 설정할 수 있습니다. 화면을 바꾸면 웹캠이 메인 화면이 되고 캡처 카드가 오버레이가 됩니다.
- **스냅샷**(`S`): 현재 화면을 PNG로 저장합니다.
- **녹화**(`R`): H.264 영상과 192kbit/s AAC 오디오로 된 MP4입니다. 비트레이트는 스트림에 맞춰 정해집니다(너비 × 높이 × fps × 0.12, 8~50Mbit/s 범위. 1080p60은 약 15Mbit/s, 4K60은 50Mbit/s). 녹화하는 동안 연결 상태에 REC와 경과 시간이 표시됩니다.
  - **Windows**: 소프트웨어 인코더는 포함되어 있지 않습니다. 녹화하려면 NVIDIA(NVENC), AMD(AMF), Intel 그래픽의 하드웨어 인코더나 Windows에 내장된 H.264 인코더(Media Foundation, Windows 'N' 에디션은 Media Feature Pack 필요)가 있어야 합니다.
  - **Linux**: 마찬가지로 소프트웨어 인코더는 포함되어 있지 않습니다. 녹화하려면 VA-API를 통한 Intel 또는 AMD 그래픽(VA-API 드라이버 설치 필요), NVIDIA NVENC(독점 드라이버), AMD AMF 중 하나가 있어야 합니다.
  - 하나도 없어도 다른 기능은 모두 쓸 수 있지만, 녹화를 누르면 '비디오 인코더 없음: 녹화하려면 NVIDIA, AMD 또는 Intel 그래픽이 필요해요'라고 안내합니다.
- **마이크 녹음**(`M`): 내 목소리를 게임 소리와 함께 섞어 녹음합니다.
- **파일 이름과 저장 위치**: `UVC Studio 2026-10-06 21.30.15.png` / `.mp4`(날짜와 시각, 같은 이름이 있으면 번호 추가). 스냅샷은 **사진/UVC Studio**, 녹화는 **동영상/UVC Studio**에 저장되며 'Pictures/UVC Studio에 저장됨' 알림과 **보기** 버튼이 나타납니다. 설정 → 일반의 '스냅샷 폴더 열기', '녹화 폴더 열기'로도 열 수 있습니다. Quest에서는 갤러리(`Pictures/UVC Studio`, `Movies/UVC Studio`)에 저장되어 파일 앱이나 USB로 확인할 수 있습니다.

## Meta Quest

헤드셋의 USB-C 포트에 캡처 카드를 꽂으면 크기를 바꿀 수 있는 창이나 거대한 가상 스크린에서 게임을 즐길 수 있고, 진짜 입체 3D도 볼 수 있습니다.

- **설치**: Meta Horizon Store에서 설치(출시 예정)하거나, 헤드셋을 개발자 모드로 바꾼 뒤 이 프로젝트의 Releases에서 `UVCStudio-Quest-v1.1.0-Free.apk`를 설치합니다(Meta Quest Developer Hub, SideQuest 또는 `adb install`). 플래티넘은 스토어에서 설치한 버전에서만 구매할 수 있습니다.
- **연결**: USB-C OTG 어댑터나 허브를 거쳐도 됩니다. 캡처 카드를 꽂을 때 UVC Studio를 열지 묻는 창이 뜨면 허용하고('항상' 선택), Android가 USB 캡처 카드에 요구하는 카메라와 마이크 권한도 허용하세요. 헤드셋 자체의 카메라는 절대 사용하지 않습니다.
- **디코딩**: H.264·HEVC 캡처 카드는 헤드셋에 내장된 하드웨어 디코더로 디코딩하며, 함께 들어 있는 FFmpeg는 MJPEG에만 쓰입니다.
- **2D 창**(기본): 데스크톱 버전과 같은 인터페이스를 옮기고 크기를 바꿀 수 있는 Horizon OS 패널에 보여 줍니다. 화면을 두 번 핀치하면 전체 화면을 켜고 끕니다.
- **몰입 모드**: Dock 맨 끝(설정 다음)에 있는 헤드셋 버튼으로 거대한 가상 스크린으로 전환하고 다시 돌아옵니다. 전환할 때마다 UVC Studio가 알아서 연결을 해제했다가 다시 연결합니다.
- **Quest의 3D 입체감**: 2D 창에서는 '입체감 없음' 또는 '입체감 효과', 몰입 모드에서는 '입체감 없음' 또는 '스테레오 3D 대형 화면'을 고를 수 있습니다.

| 몰입 모드 조작 | 방법 |
| --- | --- |
| 컨트롤 패널 클릭 | 컨트롤러로 가리키고 트리거를 당기거나, 손으로 핀치 |
| 컨트롤 패널 이동 | 패널 아래의 흰색 막대를 잡고 끌기. 밀거나 당기면 거리가 바뀜. 설정 → VR → '패널 위치 초기화'로 되돌리기 |
| 스크린 이동 | 스크린 아래의 흰색 막대를 잡고 끌기. 손을 밀거나 당기면 거리가 바뀜 |
| 스크린 크기 조절 | 모서리를 가리켜 괄호 모양이 나타나면 핀치한 채로 끌기 |
| 가깝게 / 멀리, 작게 / 크게 | 썸스틱 위 / 아래, 왼쪽 / 오른쪽 |
| 컨트롤 패널 숨기기 / 보이기 | 스크린에서 두 번 핀치, 또는 B·Y·메뉴 버튼 |
| 다시 가운데로 | Meta 버튼 길게 누르기 |
| 스크린 프리셋 | 설정 → VR: 배경(패스스루 또는 어두운 방), 화면 형태(평면 또는 곡면), 화면 크기, 화면 거리, 주사율 72 / 90 / 120Hz(기본 90) |

- **시스템 메뉴**: 열려 있는 동안에도 앱은 계속 그리며, 포인터를 숨기고 소리를 끕니다.
- **발열 줄이기**: 업스케일은 거대 스크린에서 실제로 구분할 수 있는 해상도(1도당 약 30픽셀, 최대 너비 2560)까지만 하고, 양쪽 눈 화면도 같은 크기로 렌더링합니다.
- **과열 보호**: Android 온도 상태와 OpenXR 온도 알림을 함께 확인합니다. 헤드셋이 따뜻해지면 FSR과 72Hz로 바꾸고, 너무 뜨거워지면 업스케일과 3D 입체감을 일시 중지합니다. 사용자 설정은 바뀌지 않으며, 식으면 알림으로 알려 줍니다.
- **부하 표시**: 연결 중에는 설정 → 정보에 프레임당 GPU 시간, 처리 해상도, 헤드셋 온도가 표시됩니다.

## 인터페이스

인터페이스 전체가 Liquid Glass 스타일입니다. 반투명한 젖빛 유리 같은 면 뒤로, 연결 중에는 게임 화면을 흐리게 하고 채도를 높인 모습이 비쳐 보입니다.

- **상단 바**: 왼쪽에 UVC Studio 로고, 가운데에 **연결 상태**('연결 안 됨' / 초록 점과 장치 · 해상도 · fps, 업스케일 중에는 ▸ 4K와 방식 이름, 3D 입체감을 켜면 · 3D / 녹화 중에는 깜박이는 빨간 REC와 녹화 시간), 오른쪽에 언어 메뉴와 **연결 / 연결 해제** 버튼이 있습니다. 오류는 연결 상태 아래에 빨간 글씨로 몇 초간 표시됩니다.
- **Dock**: '스냅샷·녹화·마이크 녹음', '4K 업스케일·레트로 화면·3D 입체감·좌우 반전', '웹캠 오버레이·듣기', '설정' 네 그룹으로 나뉩니다. 포인터를 올린 버튼이 커지고, 켜진 기능은 브랜드 그라데이션으로 빛나며, 툴팁에 단축키도 함께 표시됩니다. 왼쪽 아래에는 버전, 오른쪽 아래에는 전체 화면 버튼이 있습니다.
- **설정**: 큰 유리 패널에 카드를 최대 3열로 고르게 배치해 스크롤 없이 모두 조정할 수 있습니다. 소스, 사운드, 영상, 웹캠 오버레이, 화면(테마·인터페이스 크기), VR(Quest 몰입 모드), 일반, 3D 입체감, 정보 순서이며, 자동 배치에서는 '3D 입체감' 카드가 '정보' 바로 위에 있습니다. '정보'에는 버전, 연결 중일 때의 프레임당 GPU 시간과 처리 해상도(Quest에서는 헤드셋 온도도), '오픈 소스 라이선스' 버튼이 표시됩니다. 개인정보 보호 안내는 이 버튼으로 여는 화면에 있습니다.
  - **카드 접기**: 각 카드 제목 줄 맨 오른쪽, 자물쇠 오른쪽의 둥근 화살표 버튼으로 카드를 제목 줄만 남기고(제목, 자물쇠, 접기 버튼은 그대로) 접고 다시 펼칩니다. 아래 카드는 위로 올라오고, 열이 바뀌지 않으며, 접은 상태는 기억됩니다.
  - **카드 직접 배치하기**: 모든 카드의 머리글 오른쪽 위에 자물쇠가 있으며, 처음에는 모든 카드가 잠겨 있습니다. 자물쇠('이동하려면 잠금 해제')를 클릭한 뒤 카드 머리글을 드래그하면 세 열 안의 다른 위치로 옮길 수 있습니다. 놓일 자리에는 빈칸이 표시되고, `Esc`를 누르면 드래그가 취소됩니다. 자물쇠('위치 잠금')를 다시 클릭하면 카드가 고정됩니다. 잠긴 카드는 제자리에 머물고, 잠금을 해제한 카드가 그 사이를 이동합니다. 배치와 잠금을 해제한 카드는 기억되어 다음 실행 때도 그대로입니다. 직접 정한 배치를 사용하는 동안에만 닫기 버튼 옆에 '레이아웃 초기화'가 나타나며, 누르면 자동 배치로 돌아가고 모든 카드가 다시 잠깁니다. 창이 좁아 세 열을 표시할 수 없으면 자동 배치가 표시되며, 직접 정한 배치는 저장된 채로 남아 창을 다시 넓히면 돌아옵니다. Quest의 2D 창에서도 컨트롤러 포인터로 똑같이 사용할 수 있습니다.
- **언어**: 台灣正體中文, English, Deutsch, Français, Italiano, Español, Português, 日本語, 한국어, 简体中文, ไทย, Tiếng Việt 12개 언어를 오른쪽 위 유리 메뉴에서 고를 수 있습니다. 처음 실행할 때는 시스템 언어를 따릅니다.
- **테마**: 자동(06:00~18:00 라이트), 다크, 라이트.
- **인터페이스 크기**: 화면에 맞춰 자동으로 조정됩니다(1080p 100%, 1440p 약 135%, 4K 200%). 설정 → 화면 또는 `Ctrl` `+` / `−` / `0`으로 바꿀 수 있습니다.
- **글꼴과 아이콘**: Manrope와 IBM Plex Sans(태국어는 IBM Plex Sans Thai, 한중일 문자는 Noto Sans CJK TC)를 사용하며, 아이콘은 모두 UVC Studio가 직접 그린 것입니다.
- **전체 화면**: `F`, `F11`, 오른쪽 아래 버튼, 또는 화면 더블클릭. `Esc`로 빠져나옵니다.

## 개인정보 보호

UVC Studio는 모든 작업을 사용자의 기기에서 처리합니다. 화면, 소리, 녹화 파일은 기기 밖으로 나가지 않습니다. 계정도, 업로드도, 추적도 없으며 앱은 네트워크에 접속하지 않습니다. Meta Quest에서 플래티넘 구매와 구매 확인은 헤드셋의 Meta Horizon Store 서비스를 통해 이루어지며, UVC Studio 자체는 아무것도 보내지 않습니다. 전체 개인정보 처리방침은 [PRIVACY.md](PRIVACY.md)에 있습니다.
